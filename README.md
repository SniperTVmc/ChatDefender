# ChatDefender

ChatDefender is a powerful Minecraft plugin designed to protect your server's chat from spam, advertisements,
and inappropriate content.<br>
With customizable settings and advanced filtering options,
ChatDefender ensures a safe and enjoyable chat experience for all players.
